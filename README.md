# Raven AI 一人公司工具包｜免費公開版

這是一套給一人公司使用的 AI 工作流技能包。技能包會告訴 AI 助理如何協助你整理資料、製作內容、處理重複工作、經營社群與建立網站。你可以只安裝目前需要的部分。

## 怎麼開始

1. 把這個儲存庫的網址貼給能操作本機檔案的 AI Agent，例如支援技能安裝的 ChatGPT／Codex 或 Claude Code。
2. 告訴它：「請閱讀 [INSTALL.md](INSTALL.md)，先列出我可以選的技能包，再協助我安裝需要的技能。」
3. Agent 會依所選技能包的安裝說明，檢查你的電腦環境、必要工具與使用限制。需要登入服務、授權或產生費用時，由你確認。

如果 Agent 無法直接讀取 GitHub 儲存庫，可以在 GitHub 下載 ZIP，解壓後把資料夾交給它。本儲存庫公開可讀，不需要購買或申請 GitHub 邀請。

## 有哪些技能包

| 技能包 | 可以協助的工作 | 安裝說明 |
|---|---|---|
| AI 剪片 | 整理素材、逐字稿、字幕與剪輯流程 | [查看](skill-packs/ai-video/INSTALL.md) |
| Google 工具自動化 | 使用 Google Apps Script 等工具處理重複工作 | [查看](skill-packs/google-automation/INSTALL.md) |
| AI 知識庫 | 整理、查找與運用自己的資料 | [查看](skill-packs/ai-knowledge-base/INSTALL.md) |
| 社群媒體管理 | 規劃內容、審核發布與回顧成效 | [查看](skill-packs/social-media/INSTALL.md) |
| 官網打造 | 規劃、建立與維護一人公司的網站 | [查看](skill-packs/website-building/INSTALL.md) |
| WordPress MCP 工作流 | 使用自己的帳號連線並管理 WordPress.com 網站 | [查看](skill-packs/wordpress-workflow/INSTALL.md) |
| AI Agent 規則與技能盤點 | 看懂並整理電腦上的 Agent 規則與技能 | [查看](skill-packs/agent-inventory/INSTALL.md) |

每個技能包可以單獨安裝。功能需要的帳號、軟體和實機驗證範圍各不相同；請讓 Agent 先讀取該套件的 `INSTALL.md` 與 `install.manifest.toml`，再決定是否安裝與使用。
