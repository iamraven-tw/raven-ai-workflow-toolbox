# 自動化頁面檢查

`check_site.py` 只看靜態輸出。版面、響應式與互動要靠瀏覽器。

## 優先順序

1. 用戶端內建的瀏覽器工具（Claude Code、Codex、Antigravity 各自的瀏覽器能力）。不需要額外安裝。
2. 沒有瀏覽器工具時，評估 Playwright（官方 npm 套件，Apache-2.0）。安裝前說明容量（瀏覽器二進位檔數百 MB）、來源與只在本機使用；使用者拒絕就只回報 `check_site.py` 結果，並明列未做的檢查。
3. 兩者都不可用時，不要求使用者自己打開瀏覽器逐頁看；回報缺口並停在本機建置層級。
