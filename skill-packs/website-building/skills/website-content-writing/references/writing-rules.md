# 寫作規則與引導方式

## Agent 先完成文案

Agent 依商業事實與既有素材完成已選頁面文案，標記 `user_fact` 或 `ai_suggestion`，與設計推薦一起交給人類批次確認。欄位指南是 Agent 自查工具，不是人類填寫問卷；不要求人類逐句重寫。缺少會影響真實性的資料才集中補問，不編造。

必填欄位依已選頁面檢查；未選的關於、聯絡或部落格不阻擋定稿。文案的 AI 來源標記保留為出處，不把已採用的文字永遠叫做未完成範例。

## 語言

- 繁體中文、臺灣慣用語，句子短，一句一個意思。
- 不用 emoji、不用驚嘆號堆疊、不用「業界領先」「最專業」這類無法驗證的形容。
- 對讀者用「你」；站主是個人用「我」，是團隊用「我們」。

## 事實邊界

- 數字、年資、客戶數、案例、獎項、合作對象：只有設定檔或使用者素材裡有的才能寫。工具會擋 `ai_suggestion` 裡沒有依據的阿拉伯數字與「十年」「三百位客戶」這類數量宣稱。
- 信任依據為空時，AI 範例只寫工作方式與承諾，不暗示有經驗或客戶。
- 回覆時間、價格、保證成果都是承諾，使用者說過才寫。
- 使用者要加新事實時，先確認是真的，回 `website-setup` 加進設定檔，再回來改文案。

## 語氣對照

依 `website/design.json` 的主題微調範例語氣，但事實與結構不變：

| 主題 | 語氣 |
|---|---|
| 小夜燈 | 親切自介，像本人打招呼 |
| 暗房 | 短句、明確、有主張 |
| 白盒子 | 極簡，能刪就刪 |
| 日光 | 一句話一個畫面 |
| 晨光 | 口語、有節奏，但不裝可愛 |
| 週刊 | 新聞導言式，先講結果 |
