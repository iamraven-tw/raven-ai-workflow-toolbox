# 寫作規則與引導方式

## 先講原則

AI 寫的文案通常不像本人，也容易寫出沒有依據的句子。所以本技能的工作不是代寫，而是：

1. 告訴使用者哪些欄位一定要有文字、每欄在網站上出現在哪、讀者看它要得到什麼。
2. 每欄給一個虛構範例示範長度與寫法，讀 `assets/field-guide.json`。
3. 使用者自己寫最好；他沒空時 AI 可以先填一個起點並標 `ai_suggestion`，但要明講「建議你自己改過一遍」。
4. 事實只能來自設定檔或使用者本人。

## 必填與可選

`guide` 命令會列出。必填五項：首頁主標題、首頁導言、關於頁導言、關於頁至少一段、聯絡頁導言。其餘留空會沿用主題自己的預設語氣，不影響上線。

## 引導的說法

- 一次列完整份指南，讓使用者知道全貌，再從必填開始。
- 每欄用「這欄在網站的哪裡、讀者看它要知道什麼、字數、一個範例」四件事說明，不長篇大論。
- 使用者說「你先寫」時，AI 填的每一句都標 `ai_suggestion`，並在預覽表用一句話提醒：這些是範例，建議親自改。
- 使用者說「用你的範例就好」時，尊重他的決定，但在上線報告裡列出哪些欄位仍是 AI 範例。

## 語言

- 繁體中文、臺灣慣用語，句子短，一句一個意思。
- 不用 emoji、不用驚嘆號堆疊、不用「業界領先」「最專業」這類無法驗證的形容。
- 對讀者用「你」；站主是個人用「我」，是團隊用「我們」。

## 事實邊界

- 數字、年資、客戶數、案例、獎項、合作對象：只有設定檔或使用者素材裡有的才能寫。工具會擋 `ai_suggestion` 裡沒有依據的阿拉伯數字與「十年」「三百位客戶」這類數量宣稱。
- 信任依據為空時，AI 範例只寫工作方式與承諾，不暗示有經驗或客戶。
- 回覆時間、價格、保證成果都是承諾，使用者說過才寫。
- 使用者要加新事實時，先確認是真的，回 `website-setup` 加進設定檔，再回來改文案。

## 語氣對照

依 `website/design.json` 的主題微調範例語氣，但事實與結構不變：

| 主題 | 語氣 |
|---|---|
| 小夜燈 | 親切自介，像本人打招呼 |
| 暗房 | 短句、明確、有主張 |
| 白盒子 | 極簡，能刪就刪 |
| 日光 | 一句話一個畫面 |
| 晨光 | 口語、有節奏，但不裝可愛 |
| 週刊 | 新聞導言式，先講結果 |
