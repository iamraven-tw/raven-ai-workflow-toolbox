# 六大視覺調性

`website-setup` 推薦一個調性並說明理由，然後直接呼叫 `website-design-preview` 產生本機畫廊展示六個內建主題（各參考一個公開示範頁的版面手法自行實作，不是換色），讓使用者看圖選號；不要只用文字描述風格。每個調性各有一個主題，全部參考公開示範頁的版面手法自行實作，內建動畫（進場、逐字上升、跑馬燈、視差、懸停）。

| 識別 | 調性 | 適合的受眾與定位 |
|---|---|---|
| `personal_friendly` | 親切個人：以人為主角、有表情的招呼、彩色點綴、像跟本人打招呼 | 自由工作者、設計師、教練、以個人名字經營的品牌 |
| `dark_immersive` | 暗黑沉浸：深色、高對比、科技感 | 軟體、AI、影音製作、想強調專業與前沿 |
| `clean_minimal` | 極簡純淨：白底、大量留白、用色克制 | 顧問、設計、專業服務、想強調可信與清楚 |
| `photo_showroom` | 攝影展廳：全幅照片主導、介面退居幕後 | 攝影、餐飲、空間、實體商品、有大量好照片 |
| `colorful_energetic` | 鮮豔活力：多彩、大膽、有能量 | 創意工作室、活動、面向年輕受眾 |
| `editorial_press` | 雜誌印刷：報刊排版、嚴謹文字層次 | 媒體、評論、深度內容、以文章為主的網站 |

推薦規則：

- 一人公司形象站沒有大量照片時，不推薦 `photo_showroom`。
- 使用者以文章為主要內容時，優先 `editorial_press`。
- 無法判斷時，預設 `clean_minimal`，因為最不容易出錯。

風格庫中以真實品牌命名的風格只以調性呈現；不把任何品牌名寫進預設值或設定檔的推薦理由。
