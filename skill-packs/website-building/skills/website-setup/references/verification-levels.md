# 驗收分層

目前先完成所有工具包的本機實作、靜態與虛構測試，最後集中實機驗收。Node 建置可在本機選擇性執行；Wrangler 登入、`workers.dev` 部署、自訂網域、真實外部服務與另一臺電腦仍延後。逐技能的流程確認照常進行；測試延後不免除授權，也不掩蓋尚未實作的程式缺口。
