# 驗收分層

目前先完成所有工具包的本機實作、靜態與虛構測試，最後集中實機驗收。Node 建置、Wrangler 登入、`workers.dev` 部署、自訂網域、另一臺電腦皆延後；逐技能的流程確認照常進行。測試延後不免除授權，也不掩蓋尚未實作的程式缺口。

| 層級 | 成功證據 | 不能宣稱 |
|---|---|---|
| 靜態結構與文件 | manifest、檔案、frontmatter、連結與隱私掃描通過 | 技能已被 Agent 發現 |
| 本機技能發現 | 隔離安裝後，實際掃描入口可看到技能名稱與說明 | 設定或建置可用 |
| 本機設定 | 預覽、確認、原子寫入與讀回雜湊一致，且不含秘密 | 專案已建立 |
| 範本建置 | `npm ci` 與 `astro build` 在目標環境成功並產出 `dist/` | 頁面內容正確 |
| 自動化頁面檢查 | 三個斷點截圖、404、內部連結、圖片尺寸與 meta 檢查通過 | 網站已上線 |
