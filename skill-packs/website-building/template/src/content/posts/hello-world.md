這是起始範本附的範例文章，用來確認文章列表、單篇頁面、目錄與 RSS 都正常運作。正式上線前請刪除或改寫。

## 這個網站的用途

介紹我提供的服務、分享工作方法，並讓有需要的人可以直接聯絡我。

## 之後怎麼更新

1. 在 `src/content/posts/` 新增一個 Markdown 檔。
2. 填好 frontmatter 的標題、日期、摘要與標籤。
3. 重新建置並部署。

## 文章格式

段落、清單、引言與程式碼區塊都會套用閱讀排版。

> 引言會顯示成這樣。

```bash
npm run build
```
