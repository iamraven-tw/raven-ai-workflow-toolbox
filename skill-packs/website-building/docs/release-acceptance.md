# 0.7.0 Preview 本機驗收

日期：2026-09-13。本文件保存官網七技能先前的本機驗收證據；當時尚未進行 commit、tag、push、GitHub Release 或 repository 公開變更。後續維護者已指定完整工具包 v0.1.0-preview.1 的發布範圍；整套發布及公開下載驗證結果見 母專案的 GitHub prerelease。

## 已取得證據

- 套件靜態驗證：frontmatter、相對連結、Python 語法、JSON、公開內容規則與授權必要檔。
- skill-creator 的 quick_validate：七技能全部通過。驗證器需要 PyYAML；系統與隨附 Python 原先皆缺少，僅在任務專用隔離目錄安裝 PyYAML 6.0.2（PyPI wheel）後執行，未更動系統或套件執行期依賴。
- 最終乾淨獨立副本：77 項測試，74 通過、3 略過，無失敗；包含 WEBSITE_NODE_ACCEPTANCE=1 的實際建置。略過均因 Windows 未授予 symlink 建立權限；不代表連結安全已完成跨平台驗收。
- Node 真實驗收：Windows x64、既有 Node 24.19.0、npm 10.9.3。從安裝副本建立網站、npm ci、六主題各自 build／check_site、包含可選頁面與文案；另完成啟用四種服務入口的真實 Astro 建置。沒有向真實供應商送出資料。
- 備份：虛構來源建立 ZIP、逐檔雜湊、來源變更拒絕、只復原至新目錄、zip-slip／Windows 特殊路徑拒絕、失敗時不移除其他程序建立的目錄或暫存檔。
- 工作區：指定狀態範圍找到原有 0.5.0 登錄，原五技能雜湊吻合；正常更新至 0.7.0，七技能雜湊全部吻合，原五技能可由 snapshot 回復。沒有另立 migration-quarantine。
- Codex CLI 0.154.0-alpha.6.2：全新本機 app-server 的 skills/list（forceReload=true）發現七技能且 enabled=true，官網技能解析錯誤為零；未啟動模型任務。
- 安裝管理器追加修正：不同套件登錄的分流、更新計畫綁定狀態雜湊、新增入口衝突拒絕；8 項針對性測試通過，且已納入上述最終 77 項完整回歸。
- ZIP 打包器測試：固定內容可重現、排除快取、獨立文件可驗證、不覆蓋既有輸出、隨安裝保留離線畫廊授權。

## 修正而非新增服務

排除測試快取；正式搜尋／預覽／更新／遷移流程；回復時恢復原技能數量；備份還原路徑保護；預設主題 whitebox；依固定依賴校正 Node 要求；已公開網站更新不重設 noindex；七技能能力矩陣；離線畫廊內嵌程式／樣式的授權文字。套件沒有新增帳號、Cloudflare 資源、監控排程或真實網站備份。

環境警告：系統 Node 22.18.0 不符合部分固定依賴的 engines，故未拿它當成功驗收環境；切換只作用於測試子程序，未更改系統安裝。首次依賴下載曾出現 npm 可選套件清理警告；最終成功／失敗依下方乾淨回歸與實際建置結果判定。
