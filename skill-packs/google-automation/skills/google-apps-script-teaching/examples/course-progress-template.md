# Learn-GAS：課程進度

## 學習選擇

- 目前選擇：`not_selected`
- 課程工作區：由 Agent 管理（不記錄私人絕對路徑）
- 最近檢查日期：YYYY-MM-DD

第一階段與第二階段沒有先修限制，學員可在開始前自由選擇。第一階段五個案例彼此獨立，可自由選擇任一未完成案例；第二階段八課共用同一個累積專案，進入後固定依序完成第 1 至第 8 課，只能中斷並在下次從最早未完成處恢復，完成第 8 課前不得切換階段。

本檔由 Agent 在學員第一次選擇階段時自動建立；已存在時絕不覆寫。每次可驗證的狀態轉換後，Agent 使用受控進度工具更新，不要求學員手動維護。

本文件不得記錄 Script ID、Deployment ID、Spreadsheet ID、Form ID、Folder ID、Email、Token、私人網址、私人絕對路徑或其他私人資料。

## 阻塞紀錄

沒有阻塞時填寫「無」。發生錯誤時只記錄不含私人資料的摘要、重現入口及下一個假設；完整依全域除錯流程處理。
