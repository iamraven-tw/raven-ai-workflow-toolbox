# Google Apps Script 繁體中文介面用語

## 使用規則

- 教學步驟一律使用 Google Apps Script 畫面實際顯示的繁體中文名稱，不自行翻譯按鈕。
- 所有概念都依[初學者術語規則](../../learner-facing-terminology.md)先用白話說明，再使用「中文名稱(English)」，例如「網路應用程式(Web App)」；實際操作仍以畫面上的正式中文名稱為準。
- Google 更新介面，或帳號類型造成選項不同時，請使用者回報畫面文字或提供截圖。沒有核對前不得猜測名稱。
- Agent 預設只用文字引導；只有使用者明確要求時才操作 UI。
- 只要指示使用者開啟、切換或操作網頁，就在同一則指示提供已核對且可點擊的目標連結；從 Apps Script 切回 Sheets、Forms、Docs、Drive 或 Gmail 時也要再次提供。
- 介面上的帳號、Script ID、Deployment ID、網址及指令碼屬性值都不得抄入教材、紀錄檔(Log)或 Git。

本表於 2026-07-28 使用 `script.google.com` 繁體中文介面實際核對。只收錄本課程會操作的區域。

## 編輯器

左側導覽列：

- `總覽`
- `編輯器`
- `專案記錄`
- `觸發條件`
- `執行項目`
- `專案設定`

本課程常用操作：

| 位置 | 畫面名稱 | 教學說法 |
|---|---|---|
| 編輯器上方 | 函式選單，提示文字為 `請選取要執行的函式` | 先在左側「檔案」選擇指定檔案，再到上方的函式選單選擇指定函式 |
| 函式選單左側 | `執行` | 按下「執行」 |
| `執行` 旁 | `偵錯` | 只有除錯課程需要時才介紹 |
| 編輯器下方 | `執行記錄` | 展開「執行記錄」並閱讀本次紀錄檔(Log) |
| 左側檔案區 | `檔案`、`新增檔案` | 只有必須直接從編輯器執行函式時，先要求使用者在左側「檔案」選擇 Agent 指定的檔案 |
| 第一次執行的 Google 授權警告 | `這個應用程式未經 Google 驗證`、`進階`、`返回安全的位置` | 專案名稱與教材相符時，選擇「進階」 |
| 授權警告的進階選項 | `前往「<教材名稱>」（不安全）` | 只在名稱與目前教材相符時選擇並繼續授權 |

只有首次授權、指令碼屬性、部署、安裝型觸發器或除錯等沒有產品 UI 可用的步驟，才引導學生直接操作編輯器。需要直接執行函式時使用固定句型：「在 Apps Script 左側『檔案』選擇 `<檔案名稱>`，再到上方函式選單選擇 `<函式名稱>`，最後按『執行』。」即使函式選單屬於整個專案，也不得省略先選檔案的教學定位步驟。

第二階段從第 1 課起以 Sheets 的「活動報名工具」作為共通入口。學生開啟 Agent 提供的試算表連結、重新整理，再從選單選擇當課功能；從選單啟動的執行到左側「執行項目」查看，不要求學生回編輯器重跑函式。

每一個自建教學範例第一次執行前，都要主動說明上述未驗證應用程式流程，不等學生看到警告後才補充。專案名稱、帳號或權限不符合教材說明時，不得引導略過警告。

執行記錄中的 Google 系統狀態會顯示 `開始執行`、`執行完畢`；課程自己的紀錄檔(Log)仍使用 `[開始]`、`[設定]`、`[成功]`、`[失敗]` 等繁體中文標記。

## 指令碼屬性

操作路徑與按鈕：

1. 左側點擊 `專案設定`。
2. 找到 `指令碼屬性`。
3. 點擊 `編輯指令碼屬性`。
4. 需要增加一列時點擊 `新增指令碼屬性`。
5. 在 `屬性` 與 `值` 欄位輸入資料。
6. 點擊 `儲存指令碼屬性`。

同頁也會看到 `一般設定`、`時區`、`指令碼 ID` 與 `Google Cloud Platform (GCP) 專案`。沒有在當前課程使用時，不額外教學。

## 觸發條件

左側點擊 `觸發條件`，再點擊 `新增觸發條件`。視窗標題會是 `新增「專案名稱」觸發條件`。

設定欄位的實際名稱：

- `選擇您要執行的功能`
- `選擇應執行的部署作業`
- `選取活動來源`
- `選取活動類型`
- `選取時間型觸發條件類型`
- `選取小時間隔`
- `選取分鐘間隔`
- `錯誤通知設定`
- `新增錯誤通知設定`
- `選擇要多久接收一次通知`
- `取消`
- `儲存`

本課程會用到的選項包括 `試算表`、`提交表單時`、`時間驅動`、`分鐘計時器` 與 `每 5 分鐘`。其中 `試算表` 與 `提交表單時` 只會出現在綁定試算表的專案；畫面沒有課程指定選項時先停止，不改選相近項目。

觸發條件清單會顯示 `擁有者：`、`上次執行時間`、`部署`、`事件`、`函式`、`錯誤率`。

刪除教學觸發器的實際流程：

1. 在觸發器那一列點擊 `更多選項`。
2. 選擇 `刪除觸發條件`。
3. 確認視窗標題是 `要永久刪除嗎？`，並提示 `這項操作無法復原。`
4. 按鈕為 `取消`與`永久刪除`。只有取得使用者確認後，才由使用者點擊 `永久刪除`。

## 執行項目

左側點擊 `執行項目`。這裡用於查看背景觸發器、網頁應用程式及 Webhook 的執行結果。

畫面會顯示：

- `即時顯示`
- `新增篩選器`
- `部署`
- `函式`
- `類型`
- `開始時間`
- `持續時間`
- `狀態`
- `更多選項`
- `展開`

## 部署網頁應用程式

1. 點擊畫面上方的 `部署`。
2. 選擇 `新增部署作業`。
3. 在 `選取類型` 旁開啟部署作業類型，選擇 `網頁應用程式`。
4. 依課程說明填寫 `新增說明`，並確認 `執行身分` 與 `誰可以存取`。
5. 最後的建立按鈕名稱是 `部署`；沒有取得使用者確認前不得按下。

目前個人 Google 帳號顯示的存取選項為：

- `只有我自己`
- `所有已登入 Google 帳戶的使用者`
- `所有人`

## 管理部署作業

從 `部署` 選單進入 `管理部署作業`。選單中的另一個項目是 `測試部署作業`。

管理畫面會顯示：

- `進行中`
- `已封存`
- `編輯`
- `封存部署作業`
- `版本`
- `說明`
- `部署作業 ID`
- `複製部署作業 ID`
- `網頁應用程式`
- `網址`
- `複製網頁應用程式網址`
- `執行身分`
- `誰可以存取`

更新版本的實際流程：

1. 選取要更新的部署作業。
2. 點擊 `編輯`。
3. 開啟 `版本`，選擇 `建立新版本`。
4. 取得使用者確認後才點擊 `部署`。

取得 `/exec` 網址時，點擊 `複製網頁應用程式網址`，不要複製 `部署作業 ID` 或「資料庫」網址。

封存的實際流程：

1. 選取要封存的部署作業。
2. 點擊 `封存部署作業`。
3. 確認畫面詢問 `確定要封存「部署名稱」部署作業嗎？`
4. 按鈕為 `取消`與`封存`。只有取得使用者確認後，才由使用者點擊 `封存`。
