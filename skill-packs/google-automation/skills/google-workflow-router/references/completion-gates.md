# 完成狀態與證據

每次回報都要使用下列五個狀態。沒有執行的項目標示「未執行」，不要省略。

| 狀態 | 通過證據 | 常見誤判 |
|---|---|---|
| 本機程式 | 測試、靜態檢查、建置與本機 commit | 程式存在不等於已部署 |
| Google 登入 | 唯讀讀回目前帳號或由使用者確認登入結果 | 登入不等於 OAuth scope 足夠 |
| OAuth | 實際同意結果、scope 與可撤銷位置 | OAuth 不等於業務函式成功 |
| 遠端同步／部署 | 遠端檔案、版本、服務、URL 或排程狀態讀回 | 命令結束碼不等於可見結果正確 |
| 人工驗收 | 使用者在實際 Google 資源確認預期結果 | 技術測試不等於人類已接受 |

## 回報範本

```markdown
- 本機程式：已驗證／未完成；證據：...
- Google 登入：已唯讀驗證／待使用者／不需要；證據：...
- OAuth：已驗證 scope／待設定／未執行／不需要；證據：...
- 遠端同步或部署：已讀回驗證／未授權／未執行；證據：...
- 人工驗收：通過／失敗／待使用者；證據：...
```

不得在證據中貼出 Token、Cookie、OAuth client secret、Script ID、Cloud Project ID 或真實資源網址。必要時只記錄資源類型、顯示名稱、遮罩後識別資訊與驗證時間。
