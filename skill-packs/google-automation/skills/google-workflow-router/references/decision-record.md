# 需求判斷記錄

Agent 先從現有說明、檔案與唯讀檢查填寫，再只詢問仍會改變路線的欄位。

```markdown
## Google 自動化路線記錄

- 想完成的業務成果：
- 使用者如何看出成功：
- Google 產品與資料：
- 資料擁有者／敏感度：
- 誰觸發：個人／Workspace 成員／外部服務／公開網路
- 觸發方式：手動／Google 事件／Webhook／排程／批次
- 單次執行時間、每日量、並行與延遲：
- 身分與最小權限：
- 可能費用與帳務需求：
- 主要路線：GAS／WORKSPACE_API／CLOUD_RUN_SERVICE／CLOUD_RUN_JOB／SPECIALIST_REVIEW
- 不採用其他路線的原因：

### 狀態

- 本機程式：未開始／進行中／已驗證
- Google 登入：不需要／待使用者／已唯讀驗證
- OAuth：不需要／待設定／待同意／已驗證 scope
- 遠端資源或部署：未授權／已授權待執行／已讀回驗證
- 人工驗收：待執行／通過／失敗
```

不要在記錄中填入帳號、Token、secret、Script ID、Cloud Project ID 或真實資源網址。需要辨識目標時，讓相關工具在本機安全使用，對使用者只顯示名稱、類型與必要的遮罩資訊。
