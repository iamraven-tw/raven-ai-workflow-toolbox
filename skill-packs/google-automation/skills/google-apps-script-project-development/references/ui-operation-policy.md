# UI 操作原則

本規則適用於教學與實際專案中的 Google Apps Script、Google Sheets、Google Docs、Google Forms、Google Drive 與 Gmail 介面操作。

## 預設分工

- Agent 預設不操作使用者的電腦或瀏覽器 UI，只處理程式、終端機、本機檔案、測試準備與可由命令驗證的項目。
- 教學模式中，建立全新練習檔案與套用最終教材名稱屬於 Agent 的課前準備；取得遠端建立確認後直接完成，不拆成學生的建立與改名 UI 步驟。
- 第一次建立並驗證教學 Apps Script 專案後，Agent 立即在目前的私人教學對話提供可點擊的 Apps Script 編輯器網址。不得另外顯示原始 Script ID，也不得把網址寫入教材、紀錄檔(Log)、課程進度或 Git。
- Agent 使用文字引導使用者親自操作 UI。每次只提供一個小步驟，等使用者回報結果後再進行下一步。
- 使用者負責實際操作、畫面確認、授權與最終成果判斷。Agent 不得把程式測試通過或命令執行成功，當成 Google 端成果已驗證。
- 只有使用者明確要求 Agent 協助操作 UI 時，才可操作當次指定的畫面與動作；這項同意不延伸到其他頁面或後續操作。
- 即使使用者要求操作 UI，`clasp push`、觸發器、部署、寄信及其他會改變遠端狀態的動作，仍須遵守各自的確認規則。

## 網址先行

- 只要要求使用者開啟、切換或操作任何網頁，就必須在同一則指示中提供已核對且可點擊的目標連結。
- 適用範圍包括 Apps Script、Sheets、Forms、Docs、Drive、Gmail、Google 帳戶授權頁、deployment、Web App 及任何外部參考網站。
- 如果下一步要從一個 Google 服務切換到另一個服務，例如從 Apps Script 回到 Sheets 驗收，新的指示必須再次附上目的地連結，不得假設使用者仍保留或知道原頁面。
- 若尚未取得或無法核對目標連結，Agent 先取得並核對；在連結可提供前，不得要求使用者自行尋找或操作該頁面，也不得捏造網址。
- 實際專案的私人資源連結只放在目前的私人對話，不寫入教材、紀錄檔(Log)、課程進度或 Git。

## 指引格式

每個 UI 步驟都要簡短包含：

1. 現在要開啟的頁面或位置，以及可點擊的目標連結。
2. 要點選的正確繁體中文介面名稱。
3. 需要輸入或選擇的內容。
4. 完成後應看到的結果。

Apps Script 的操作用語以 [Apps Script 繁體中文介面用語](../../google-apps-script-teaching/references/apps-script-ui-zh-tw.md) 為準。例如使用「執行」、「執行記錄」、「專案設定」、「指令碼屬性」與「觸發條件」，不得自行翻譯成相近但不存在的按鈕名稱。

其他 Google 服務若尚未收錄正確用語，Agent 必須先核對目前的繁體中文介面或 Google 官方繁體中文說明。無法確認時，請使用者提供目前畫面上看到的文字或遮蔽敏感資訊後的截圖，不得猜測按鈕名稱。

## 使用者必須親自完成的操作

除非使用者明確要求 Agent 操作 UI，以下項目一律由使用者完成：

- Google 帳號登入、OAuth 授權及權限確認。
- 在「專案設定」的「指令碼屬性」新增或修改設定值。
- 只有按鈕、圖片或繪圖本身是明確需求或教學目標，且已決定不使用自訂選單時，才由使用者在 Google Sheets 指派要執行的函式。一般日常入口由 Agent 以 `onOpen(e)` 建立自訂選單，使用者只需重新整理試算表並使用選單。
- 在 Apps Script 左側「檔案」選擇 Agent 指定的檔案，再到上方函式選單選擇指定函式並按「執行」。
- 建立、更新或刪除「觸發條件」與「執行項目」。
- 建立或管理部署、複製網頁應用程式網址。
- 寄信、提交表單、開啟產生的文件及其他真實成果測試。

Agent 在請使用者執行函式前，必須同時說明函式名稱、所在檔案、用途、預期的繁體中文紀錄檔(Log)，以及要在編輯器下方「執行記錄」確認什麼。所有教學操作都使用固定順序：「在 Apps Script 左側『檔案』選擇 `<檔案名稱>`，再到上方函式選單選擇 `<函式名稱>`，最後按『執行』。」不得省略先選檔案的步驟。

每一個自建教學範例第一次執行前，Agent 都要預告 Google 可能顯示「這個應用程式未經 Google 驗證」。只有畫面上的專案名稱與目前教材相符時，才引導使用者選擇「進階」及「前往『<教材名稱>』（不安全）」繼續授權；名稱、帳號或權限不符時立即停止。必須說明這是自建教材尚未送 Google 公開驗證，不是允許略過任意程式的安全警告。

## 畫面不同時

若使用者看到的介面與指引不同：

1. 立即停止後續 UI 步驟。
2. 請使用者回報目前頁面與畫面上實際顯示的繁體中文文字。
3. 必要時請使用者提供遮蔽帳號、Script ID、網址、Token 與個資後的截圖。
4. 核對後再提供下一個步驟，不以英文名稱或推測翻譯要求使用者尋找。
