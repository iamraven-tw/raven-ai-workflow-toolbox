# 技能目錄

本目錄只保存 `My Real Second Brain` 自行撰寫的技能：

- `my-real-second-brain-setup`
- `solopreneur-profile`
- `book-notes`
- `knowledge-source-retrieval`
- `socratic-dialogue`

Graphify 的技能及程式不會複製到這裡。本地 RAG 的匯入與查詢腳本是自有程式，隨工作區範本放在 `template/sources/rag/scripts/`。`my-real-second-brain-setup` 會引導 AI Agent 依 `install.manifest.toml` 安裝五個自有技能，再安裝並驗證 Graphify 與本地 RAG（Ollama、向量模型與 Python 環境）。
