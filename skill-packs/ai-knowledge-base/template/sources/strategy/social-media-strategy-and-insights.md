# 社群媒體策略與洞察

這份檔案保存使用者已確認的社群經營方向，以及經過人類討論後成立的長期洞察。它不是原始成效資料庫，也不會因單篇貼文或一次報告自動改寫。

## 維護規則

- 策略、洞察與假設分開記錄，不把 AI 推論寫成使用者決定。
- 每週、每月、每季與每年報告先整理觀察，再與使用者討論並加入使用者判斷。
- 寫入前顯示準備新增、修改與保留的內容；取得明確確認後才更新。
- 每項洞察保留檢視期間、證據位置、適用範圍、信心與最後人工檢視日期。
- 原始指標、逐篇報告、留言、平台 ID 與發布紀錄保存在各自工作區；本檔案只放摘要與可追溯位置。
- 不得保存 Token、Cookie、OAuth secret、密碼或其他憑證。
