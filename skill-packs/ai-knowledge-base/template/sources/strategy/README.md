# 策略與已確認洞察

本目錄保存使用者已確認的一人公司設定、長期策略、洞察與重要變更。內容屬於第一大腦形成的長期脈絡，不代表市場事實，也不能取代最新證據。

- `solopreneur-profile.md`：一人公司的方向、客群、價值、通路、資產、限制與近期優先事項。
- `social-media-strategy-and-insights.md`：社群經營目標、平台角色、內容方向、檢視頻率、已確認洞察與待驗證假設。
- 公開範本只包含空白欄位，不得放入真實使用者資料。
- AI 可以讀取設定檔協助回答創業問題；寫入或修改前必須先顯示差異並取得確認。
- 原始成效報告不能自動升級成洞察；必須先與使用者討論、加入使用者判斷並再次確認。
- 重大方向改變保留日期、原因與被取代內容，不靜默刪除決策脈絡。
