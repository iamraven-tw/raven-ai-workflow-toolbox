# My Real Second Brain 工作區規則

這個工作區使用 `My Real Second Brain`。第二大腦負責保存、整理、連結、檢索與提醒；閱讀、理解、判斷與最後決定仍由使用者本人負責。

## 知識層級

- `sources/strategy/`：使用者已確認的一人公司方向、客群、價值、限制、優先事項與重要變更；不是市場事實或永久承諾。
- `sources/book-notes/`：使用者直接說出、閱讀與思考後形成的第一大腦心得。優先保留接近原話的內容。
- `sources/references/`：作者文章、PDF、TXT、軟體文件、報告與 Notebook 路由等次級資料。
- `sources/wiki/`：Agent 依心得與來源整理的扁平知識頁；用 frontmatter `type` 分類，重要主張必須連回來源。
- `sources/graphify-out/`：可重建的知識結構與視覺化，不是事實或第一大腦心得的最高來源。

## 固定工作順序

1. 第一次啟動、使用者沒有提出明確任務且 `sources/strategy/solopreneur-profile.md` 尚未完成時，使用 `/solopreneur-profile` 逐步建立；已有明確任務時不阻擋工作。
2. 創業方向相關問題先讀一人公司設定，再查既有知識；設定檔新增或更新前先預覽並取得確認。
3. 只有使用者明確要求記錄一本書時，才保存其接近原話的想法，再建立整理後核心觀點；一般討論不得自動寫入，作者主張與 AI 延伸要分開標示。
4. 檢索時先讀本機 Wiki 與 Notebook 路由索引，再定向查讀書筆記、次級資料、知識結構 Provider 與相關外部集合。
5. 使用者想檢查觀點、挑戰假設、比較立場或形成決策時使用 `/socratic-dialogue`；先查第二大腦，資料不足、可能過時或缺少可信反方時再搜尋公開網路。
6. 使用網路資料時附上可以直接核對的原始網址，並說明來源支持、補充或挑戰哪一項說法。
7. `/socratic-dialogue` 每輪原則上只問一個主要問題，每二至三次使用者回答後整理共識、分歧與待查證事項，最後請使用者確認共同理解。
8. 對話與網路資料預設不寫入 `sources/`；只有使用者明確要求保存時，才依內容角色寫入 `strategy/`、`book-notes/`、`wiki/` 或 `references/`。
9. 一般一本書或單一文件不建立 Notebook；只有資料集龐大、跨大量文件，或反覆載入明顯浪費 Token 時才使用 Notebook。
10. Notebook 或其他外部檢索資料預設是探索性來源；重要內容經使用者閱讀確認後，才能整理為第一大腦知識。
11. 來源衝突時並列差異、保留引用，交由使用者判斷。

## Provider 與安全

- Graphify 與 Notebook 是預設但可替換的 Provider，不是系統本身。
- 替換 Provider 不得靜默改寫讀書筆記、Wiki 或來源索引 schema。
- 不得把 Cookie、Token、登入狀態、帳號密碼、私人 Notebook ID 或無權處理的內容寫入可公開檔案。
- 使用者既有檔案預設保留原始位置；未經明確要求不複製、不刪除。
- 刪除資料、刪除遠端來源、發布與其他高影響操作必須取得明確確認。
