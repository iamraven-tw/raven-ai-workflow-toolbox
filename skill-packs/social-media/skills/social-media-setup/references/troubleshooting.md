# 平台初始化疑難排解

## Meta 新增 permission 顯示錯誤，重新載入卻已保存

驗證日期：2026-09-09；Windows 受控瀏覽器、Meta 開發者後台的 Pages 使用案例。新增已核准 permission 後，畫面顯示「發生錯誤」，同一列暫時仍是「新增」；重新載入後該 permission 實際已成為「可供測試」。已在內容、成效及管理權限觀察到此行為。

1. 把第一次送出結果記為不明，保留目前 App、permission 與原本狀態；不要再次按新增，也不要讓人重新操作同一個按鈕。
2. 讀取並關閉錯誤提示，重新載入同一 App 的權限頁。等待頁面完成載入，核對同一 permission 的持久狀態。
3. 若已為「可供測試」，記錄後台設定保存成功並繼續；仍顯示「新增」或讀回失敗則保持未確認，先排查原因，不推定成功或反覆重送。
4. 「可供測試」只表示 App 可要求該權限。實際使用者授權、Token scope、Page 關係、內容和成效 API 仍須各自驗收。

這是實測的讀回處理方式，不代表已查明 Meta 錯誤根因，也不能套用為所有表單錯誤都已保存。Threads 回呼表單同樣必須檢查重新載入後的實際值，不能借用 Pages permission 的成功結果。
