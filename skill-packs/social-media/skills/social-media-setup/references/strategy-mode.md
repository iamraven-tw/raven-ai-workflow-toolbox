# 策略初始化模式

## 何時使用

使用者要建立或調整社群方向、尚無策略設定，或明確任務缺少平台角色與目標時使用。若已有清楚任務，只補會改變該任務結果的最低欄位。

## 問題順序

每回合只問一個主要問題，並先利用既有資料作答：

實際初始化且尚未選定平台時，先依 SKILL.md 的平台入口詢問，預設提案為 Meta 與 YouTube，允許使用者增減或指定其他平台。以下問題只補尚未確定的策略，不重問已有答案。

1. 目前最重要、可觀察的社群成果是什麼。
2. 主要服務對象及其目前問題。
3. 三至五個可持續的內容主題。
4. 被選取平台在整體內容系統中的不同角色。

不要先問發文頻率、固定時段、工具帳號或所有平台細節。這些只有在目前任務確實需要時才詢問。

## 既有策略來源

如果 `sources/strategy/social-media-strategy-and-insights.md` 存在：

- 先讀目前狀態、使用者已確認的策略與有效洞察。
- 將長期策略、逐期觀察與尚待確認想法分開。
- 檔案內容與使用者最新明確說法衝突時，以最新說法形成候選設定，但先指出差異。
- 本技能不修改該策略檔；只在一般設定中保存其相對路徑與目前需要的摘要。

## 完成判準

`configured` 不是欄位填滿的代名詞。只有主要目標、受眾、至少一個內容主題，以及每個已選平台的角色足以支援目前任務時才使用；否則標示 `partial`，但仍可繼續明確任務。
