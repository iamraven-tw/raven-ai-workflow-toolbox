# 驗收分層

目前先完成所有工具包的本機實作、靜態與虛構測試，最後集中實機驗收。真實 Terminal、原生憑證庫、登入／OAuth、平台讀取、測試發布、另一臺電腦皆延後；逐技能的流程確認照常進行。測試延後不免除授權，也不掩蓋尚未實作的程式缺口。

| 層級 | 成功證據 | 不能宣稱 |
|---|---|---|
| 靜態結構與文件 | manifest、檔案、frontmatter、連結與隱私掃描通過 | 技能已被 Agent 發現 |
| 虛構 Agent 對話前測 | Agent 完整讀取候選來源，對保存的虛構訊息產生完整回應，並記錄問題數、平台範圍與外部動作 | 安裝後的真實 Agent 已發現技能、獨立模型也會同樣執行或平台已可用 |
| 本機技能發現 | 隔離安裝後，實際掃描入口可看到技能名稱與說明 | API 可用或帳號已連接 |
| API 套件可安裝 | 固定來源、版本、授權與最小匯入測試通過 | OAuth 或平台資料可讀 |
| 媒體驗收準備 | 共用簡報、品牌設定、路由規則、負例、結果範本與靜態檢查完整 | 模型已生成、renderer／字型可用、圖片正確或人工已核准 |
| 本機憑證儲存 | 在目標作業系統以一次性虛構值完成原生寫入、讀回比對、重開程序後再讀與刪除，且輸出及參照檔均無秘密 | 平台 OAuth 已完成、另一種作業系統也可用或已授權遠端寫入 |
| OAuth 虛構程式測試 | 記憶體憑證庫、虛構 HTTP 回應與本機 loopback 協定通過 | 真實 Token 交換、HTTPS callback、瀏覽器同意或平台權限已驗收 |
| 使用者登入／OAuth | 使用者本人完成同意，且授權狀態可讀回 | 權限足以執行所有功能 |
| 憑證維護排程 | 排程已建立並讀回，首次執行以既有 Runtime 完成有效性檢查或合法刷新，且輸出不含秘密 | 平台永遠不會撤權、refresh token 永不失效或不再需要本人重新 OAuth |
| 平台讀取 | 以選定帳號讀回預期資源與權限 | 發布或回覆可用 |
| 測試發布 | 非破壞性測試逐步送出並讀回網址、ID、時間與狀態 | 其他平台或正式內容已支援 |
| 另一臺電腦驗收 | 從乾淨環境依公開文件完成安裝與指定案例 | 已正式發布版本 |
| 正式公開支援 | 七技能、依賴、合規、文件與外部驗收全部通過並另行發布 | 僅憑候選檔案即可宣稱支援 |

虛構 backend 測試不能代替 macOS Keychain 或 Windows Credential Manager 實機測試；其中一個作業系統通過也不能推定另一個通過。登入畫面、OAuth 設定頁、送出 API 請求、按下按鈕、產生平台 ID、本機狀態檔或單次刷新成功，都不是下一層成功的替代證據。需要持續維護的 OAuth 連線，只有登入與平台讀取成功但沒有已驗證排程時仍屬 `partial`。結果不明時標示不明並停止，不得盲目重送。
