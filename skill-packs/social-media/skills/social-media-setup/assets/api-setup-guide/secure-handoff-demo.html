秘密只貼到 Agent 開好的安全終端機

Facebook、Instagram、Threads、YouTube 都使用同一個交接方式。

1　你告訴 Agent 準備好了

「我準備好輸入了。」

只說這句話，不把秘密貼進對話。
Agent 說明這次要輸入的憑證種類。

2　Agent 開啟安全終端機

請貼上本次指定的憑證
（輸入不回顯；按 Enter 即確認儲存，
Ctrl+C 取消）：▌

視窗外觀因作業系統不同；這裡沒有可輸入欄位。

3　你貼上一次，再按 Enter

在真正的終端機貼上 → 按 Enter

畫面不顯示文字，通常也沒有星號，屬於正常情況。不要因此重複貼上。
接著告訴 Agent：「已輸入完畢。」

4　Agent 接續檢查並回報

範例回報：安全保存與讀回成功。
接下來核對平台帳號、權限與有效期限。
