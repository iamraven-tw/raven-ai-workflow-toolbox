# YouTube 文案

查證日期：2026-09-05。適用影片／Shorts 的標題與說明，不套用到社群貼文；Shorts 類型、片長與媒體格式由製作／發布端另驗。

- 輸出 title、body（說明欄完整文字，含 CTA／連結）、封面文字、需要時的口播腳本與素材提示。
- 官方 Data API：title 最多 100 characters；description 最多 5000 bytes，兩者不能含 < 或 >。本機以 Unicode code points 與 UTF-8 bytes 預檢；emoji 組合和平台最終計數仍以實際介面為準。
- 編輯起點而非硬限制：標題先用約 20–45 個中文字傳達對象與收益；說明前段先講影片實際涵蓋什麼，再列來源與一個主要 CTA。不得為吸引點擊加入影片沒講的承諾。
- 已有影片用實際內容與逐字稿；未拍攝的腳本不能稱為逐字稿。章節時間只能取自實際剪輯／時間碼，無影片時保留待補，不虛構 00:00 後的時間。
- 連結可點擊資格不是文案能保證；標籤非必要，不硬塞。封面與成片分別交接、審核，不在這裡生成或上傳。

來源：[YouTube videos resource](https://developers.google.com/youtube/v3/docs/videos#snippet.title)。數字適用該 API，不把 UI 的計數或其他端點視為相同。
