# Substack 文章與電子報文案

查證日期：2026-09-05。MVP 適用 article，不把 Notes、Chat 或 Podcast 當同一格式。

- 輸出 title、subtitle（可空）、body、主要 CTA、引用來源、必要的封面／內文圖需求。電子報主旨可先以文章標題為起點；替案必須由人選，不開始平台標題測試。
- 編輯起點：依原文章與使用者篇幅要求，保留論述、例子及段落；未指定可先用約 800–2000 個中文字，但不是平台上限，也不能為湊字數刪掉重要條件。
- 語氣沿用使用者既有作品，不能把貼文摘要擴寫成未發生的個人故事。付費牆、免費預覽、收件對象和寄送選項只列建議／待確認，不修改平台設定。
- [官方發文說明](https://support.substack.com/hc/en-us/articles/360037831771-How-do-I-publish-a-new-post-on-Substack) 顯示編輯器會自動存遠端草稿，並有網頁／email／app 寄送選項。因此本技能只做本機草稿，不為「預覽」打開編輯器貼入內容。
- 本輪官方資料未提供可作本技能契約的通用正文硬上限，標為未知；也不因此宣稱正式公開發文 API 可用。HTML、連結與圖片在發布前另作實際預覽。
