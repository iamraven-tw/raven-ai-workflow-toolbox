# Facebook 粉絲專頁文案

查證日期：2026-09-05。以 Page 的 post、image、video 為範圍；不擴成廣告、個人帳號或社團寫入。

- 輸出 body（開頭／主體／實際 CTA 與連結），影片或圖卡另附標題／圖上文字和媒體簡報。
- 編輯起點：正文約 150–800 個中文字。依平台角色，以情境、實際例子或可討論問題引入，補足上下文；不是固定「Facebook 語氣」或平台硬上限。
- 引用文章要清楚分開原作者說法與使用者觀點，不虛構親身經驗。連結預覽、封面裁切與換行的實際呈現須在發布端另驗。
- 不用「留言某字自動私訊」等 CTA 承諾尚未建立或核准的自動化；可以單純邀請觀點，但不擅自承諾回覆。
- 本輪先遇到 429，之後已直接取得 [Pages Posts 官方文件](https://developers.facebook.com/docs/pages-api/posts/) 並確認 message／link 欄位；該份內容未列通用字數上限，因此保留數值未知，不拿網路常見數字當正式 API 保證。本技能仍可交付草稿，發布端必須查核選定路線。
