# Threads 文案

查證日期：2026-09-05。MVP 採單則基本正文；系列以多筆草稿分開，保留順序，每則都要獨立預覽，不建立遠端回覆串。

- body 包含實際連結與 CTA，基本正文以 500 characters 為已查證上限，本機採 Unicode code points 預檢，接近上限的 emoji／組合字仍由發布端確認計數。
- 編輯起點：80–250 個中文字、一個可理解的觀點，必要時帶一個真正想討論的問題。這是起草選擇，不是平台要求，不強迫每則都問問題。
- [Meta 長文附件公告](https://about.fb.com/news/2025/09/attach-text-threads-posts-share-longer-perspectives/) 明確區分基本正文與最多 10,000 characters 的文字附件。不得把附件上限套用到正文；本技能不自動啟用附件或假設 API 已支援。
- 超過基本正文先縮寫或經使用者同意拆成多則；要求文字附件時另查當前發布路徑，先保留需求，不用普通 body 假裝支援。
- 圖片或影片只能整理需求，不因 Threads 已設定就調用生圖、影片模型或發布。
