# 社群媒體管理技能包維護規則

本目錄是公開、去識別化的技能包來源。所有範例必須使用虛構資料，不得寫入真實帳號、網址、品牌語氣、排程、平台 ID、憑證或私人檔案路徑。

## 修改邊界

- `install.manifest.toml` 是已實作技能與安裝狀態的唯一機器可讀來源。
- 尚未完成的技能只可列於 `[[planned_skills]]`，不得建立只有名稱或待辦事項的 `SKILL.md`。
- 平台登入、OAuth、建立 App、發布、留言回覆、排程與遠端寫入皆是獨立外部關卡；本機測試不得假裝這些關卡已通過。
- 憑證不得寫進技能目錄、一般設定檔、範本、測試輸出或安裝狀態。
- 不得把第三方套件、非公開端點、網頁內部請求或受控瀏覽器描述成平台正式 API。
- 平台能力與限制會變動；修改平台文件時，應重新查閱官方來源並更新查證日期。
- 公開套件與任何私人工作區都是獨立快照，不建立自動同步、symlink 或隱含複製流程。
- 真實執行若證明目前技能規則錯誤，依技能內的「執行錯誤最小回填」處理；一次只做同一技能的小修正與針對性重測，不為此展開跨技能改造。
- 只有實際驗證過的特定環境解法才建立或更新 `references/troubleshooting.md`，不得預先建立空殼或寫入私人案例。

## 驗證規則

任何完成宣告都要分開回報：靜態結構、本機技能發現、相依套件、登入／OAuth、平台讀取、測試發布、另一臺電腦驗收與正式公開支援。只有實際執行並取得證據的層級才能標示通過。
