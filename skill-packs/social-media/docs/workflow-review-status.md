## 判讀規則

- 上表是目前狀態；各 `*-local-verification.md` 仍保留建立當日的歷史結果，並以後續狀態補充，不回寫成當時已確認。
- 「流程已確認」不會替代待辦清單中的實作、官方查證、虛構 Agent 對話或集中實機驗收。
- 「本機候選」只表示套件結構、離線 helper 或虛構資料檢查已有對應證據；平台 adapter 文件本身不是已接通的 API。
- 發布、回覆、私訊與策略寫回仍保留各自的當次預覽、明確確認及讀回驗證，不會從這份流程確認自動取得授權。
