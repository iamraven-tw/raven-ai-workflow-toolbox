# 成效資料到策略完整虛構驗證

日期：2026-09-06。本文件記錄 `PERF-03` 的隔離本機驗證；沒有登入平台、讀取真實帳號、修改私人 newsletter 工作區或公開發布。

## 驗證範圍

新增 `tests/test_performance_end_to_end.py`，讓同一批虛構 YouTube 帳號層觀測依序通過：

1. 官方 API collector 的假 adapter，建立去敏感來源證據與 dataset。
2. `performance_review.py analyze`，只比較相同身分且完整的相鄰曆期。
3. 四項「事實／推論／限制」觀察與唯一一個策略問題。
4. 使用者判斷；這一步不等於策略寫入同意。
5. 完整追加文字預覽；預覽不建立或修改策略檔。
6. 缺第二次確認時停止；帶同一預覽雜湊再次確認後才寫入。
7. 寫後讀回、備份、交易與收據；原始 dataset 與報告仍留在私人 `social-media/performance/`。

weekly、monthly、quarterly、yearly 四種模式各自在獨立暫存工作區完整走一次上述流程。測試同時放入真正零值、資料不可用、權限不足、讀取失敗及定義改變；只有真正零值仍可作數值比較，其他狀態不會被補成零或接成趨勢。前期為零時只提供差值及基準提醒，不產生無限成長率。

## 寫入邊界

- 虛構原始觀測、證據、dataset 與逐期報告只位於暫存私人工作區的 `social-media/performance/`。
- 長期策略只追加已確認的精簡結論、使用者判斷、適用範圍、信心、再檢視日期及私人證據相對位置。
- 測試中的原始數字與 metric 名稱不會被搬進策略追加文字。
- 預覽前缺使用者判斷、觀察不足三項、同時提出兩題或缺第二次寫入確認都會停止。
- `.local/social-media/performance/` 保存備份、交易與讀回收據；這些都不進公開技能來源。
