## 公開與授權邊界

公開掃描檢查常見秘密格式、維護者私人名稱／路徑、私人工作區識別及非預期私用字元。manifest 與技能契約仍要求外部帳號動作明確授權，並分開記錄 OAuth、平台讀取、發布、回覆、Sheets、圖片生成與正式支援。

這些靜態規則降低誤放風險，但不是完整資安稽核，也不能證明沒有所有可能形式的私人資訊。此次沒有打開或掃描 newsletter 私人工作區；公開／私人維持獨立快照。
