# 四種製圖路徑驗收準備

日期：2026-09-06。本文件記錄 `PACK-02` 的本機準備狀態；沒有呼叫 Codex／Antigravity 生圖、網頁模型、瀏覽器或 HTML renderer，也沒有修改私人工作區。

## 已準備項目

- 一份 1080 × 1350、三頁、繁體中文的 Instagram 虛構輪播簡報。
- 一份 1080 × 1080 方形重排簡報；不可用直式圖裁切冒充。
- 四路共用的虛構品牌視覺：深青、橘色、米白、深色文字及 Noto Sans TC 字型意圖。實機仍須證明字型存在與權利。
- Codex、Antigravity、網頁模型、HTML＋CSS 各自的工具、狀態、產物與停止條件。
- 三份無 placeholder、可直接貼入網頁模型的逐頁提示詞。
- 無 JavaScript／遠端資源的三頁 HTML＋CSS 原稿。
- 故意超量繁體中文字的溢位負例，以及四路分層結果紀錄範本。
- 共用逐字、尺寸、手機縮圖、順序、替代文字、來源權利、視覺核准及發布交接關卡。

主要契約見技能內 [集中驗收簡報](../skills/social-image-production/references/acceptance-testing.md)。

## 本機測試

`tests/test_image_acceptance_preparation.py` 驗證：

- 直式三頁與方形單頁都符合既有 brief 契約。
- 四條 route 共用同一品牌設定、不修改設定，也不產生發布授權。
- 資訊密集內容走 HTML＋CSS；網頁瀏覽器代操作只限當次請求。
- HTML 是三張固定尺寸卡片、沒有 script 或遠端 `src`／`href`，含完整繁體中文與正確色票。
- 網頁提示詞逐頁包含完整 exact_text，沒有待人補寫欄位。
- 結果範本四條路徑都從 `not_run` 開始，不預先宣稱成功。

第一次測試發現 HTML 主色色碼少一碼；修正為 `#174A4A` 後重跑通過。溢位 fixture 原本有 469 個字元，測試門檻錯設為 500；只調整測試門檻為 400，沒有縮減 fixture。兩項都是本地 fixture／測試修正，不改技能主要流程，也未建立疑難排解空檔。
