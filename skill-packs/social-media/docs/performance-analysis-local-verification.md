## 保留能力缺口

1. 沒有五平台成效資料擷取器；使用宿主既有且獲授權的 API／連接器／工具或使用者匯出檔。平台文件不是已串接的 SDK。
2. helper MVP 只比完整相鄰曆期與期末快照；去年同期、固定貼文天齡、lifetime、進行中期、跨資料集合併寫回不在程式範圍。可另列人工分析，不冒用通過結果。
3. 結構與雜湊不能證明官方資料真實、正確定義、使用者本人同意或推論品質；Agent 與人類關卡仍必要。虛構 Agent 對話案例尚未逐一實跑。
4. 來源不同時區分資料集。不同月日數不同會提示；不自動平均比率、加總觸及或推論因果。
5. 寫回只追加，不自動重整舊策略、設定 configured 或同步公開內容。鎖只協調本 helper，不控制其他編輯器；Windows ACL、原子替換與真實宿主環境仍待實機驗收。
6. 未完成交易及殘留鎖須人工比對，沒有自動清除／回復功能。策略檔、原始證據及收據均是私人資料，不能搬進公開包。
