# 社群媒體技能包本機候選交付紀錄

日期：2026-09-06。候選版本：0.7.0。這份文件是本機工作收尾，不是正式公開支援、實機驗收或發行公告。

## 交付結果

七個技能均已納入安裝清單，並完成目前最小工作流的本機文件、helper、公開／私人資料邊界、虛構資料測試與隔離安裝生命週期。初始化、發布、公開留言、六欄 Google Sheets 人工審核、Facebook／Instagram 按需私訊、四週期成效分析，以及資料到策略的人工確認寫回都有明確輸入、輸出、確認關卡、讀回與停止條件。

Facebook／Instagram 私訊維持已確認的 MVP：只在使用者叫 Agent 時同步，只處理對方先發起、最新仍是對方訊息、24 小時內且最近脈絡全為純文字的對話；不建 Webhook、不背景監控、不排程，也不把私訊放入 Google Sheets。

本輪另完成：

- 目前 root Agent 對十個虛構回合的前向測試；不是獨立模型或真實安裝入口測試。
- 四種圖片路徑的共用簡報、品牌、提示詞、HTML 原稿、溢位負例與結果範本；沒有真正生成、渲染或看圖核准。
- 修改後整包回歸：382 項離線測試中 381 項通過，1 項原生憑證探測依集中實機驗收政策略過；13 項隔離安裝生命週期、7 份技能格式、失效 symlink 與差異格式檢查通過。

## 保留邊界

- 公開 Toolbox 與私人工作區維持獨立快照；沒有建立同步，也沒有讀取、搬移或寫入私人帳號、網址、品牌語氣、排程、憑證路徑或內容資料。
- 沒有登入平台、建立 App、申請 API、執行 OAuth、安裝第三方工具、讀取真實帳號、發布、回覆、傳送私訊、建立排程、commit、push 或發布版本。
- 額外平台格式、留言管理、廣告／付款／企業／商品與其他功能不為了補齊清單自動擴大。只有真實需求出現時，才一次評估一項的官方能力、權限、依賴與測試成本。
