# 七技能虛構 Agent 對話前測

日期：2026-09-06。這是 `PACK-01` 的本機前向測試紀錄，不是平台或真實安裝驗收。

## 執行方式

目前工作階段的 root Agent 完整讀取七份技能入口與既有案例，直接對十個虛構使用者訊息產生回應。每則紀錄包含實際使用者文字、Agent 回應、讀取的平台範圍及外部動作紀錄，保存在 `tests/agent-dialogue-preflight.md`。測試沒有把預期答案塞進另一個模型，也沒有使用子 Agent；因此只能證明這次同一 Agent 的前向行為，不能冒充獨立模型評估。

`tests/test_agent_dialogue_preflight.py` 讀取完整回應文字，檢查：

- 七個技能都有實際回合，不是只有 SKILL.md、檔案存在或 JSON 欄位。
- 模糊設定入口只有一個問題；明確 YouTube 任務不強迫補完初始化。
- 規劃先交三個獨立案例、揭露 YouTube 重複與 X 受限，停在唯一方向問題；使用者核准後才交文案、圖片與既有剪片技能。
- 撰寫只讀 Facebook／Instagram，交草稿與媒體需求，不生成或發布。
- 圖片沿用 Codex 偏好；既有素材影片交剪片，不誤當 AI 新影片。
- 發布只讀 Instagram／Facebook，停在完整預覽確認前，沒有 begin、claim 或遠端寫入。
- 公開留言保留六欄 RAW 與回覆的第二次確認；Facebook 私訊按需、24 小時、純文字、不建 Webhook、不進 Sheets。
- 成效回顧區分真正零值、不可用與權限不足，提供三項觀察與唯一問題，不跨平台排名或寫策略。

## 結果與限制

十個對話案例的人工判讀一致通過；自動測試另外核對可觀察文字、問題數、平台讀取範圍與外部動作紀錄。沒有發現需修改七份技能主要流程的衝突。

本次沒有執行：

- 真實 Codex、Claude、Antigravity 或 Hermes 的技能安裝／發現。
- 獨立模型盲測、不同模型一致性或長對話狀態恢復。
- 網路搜尋、圖片生成、影片剪輯、瀏覽器、OAuth、Sheets 或平台讀寫。
- 私人 newsletter 工作區、另一臺電腦、commit、push 或發布版本。

因此本結果只完成 `PACK-01` 的虛構對話前測；`LIVE-01` 的真實 Agent 入口與其餘集中實機驗收維持未執行。
