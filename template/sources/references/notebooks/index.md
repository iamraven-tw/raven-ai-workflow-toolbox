## 選擇原則

1. 依題目、同義詞與用途選出最少數量的候選。
2. 不相關的集合不連線。
3. 紀錄過期、使用者剛修改遠端內容或需要精確引用時，才同步候選集合。
4. 各集合分開查詢，整合時保留來源與引用。
