# 技能目錄

本目錄只保存 `My Real Second Brain` 自行撰寫的技能：

- `my-real-second-brain-setup`
- `solopreneur-profile`
- `book-notes`
- `knowledge-source-retrieval`
- `socratic-dialogue`

Graphify 與 `notebooklm-py` 的技能及程式不會複製到這裡。`my-real-second-brain-setup` 會引導 AI Agent 依 `install.manifest.toml` 安裝五個自有技能，再從正式上游套件來源安裝並驗證預設後端。
