# 一人公司設定檔

這個技能讓 AI 在不同任務中持續理解使用者正在經營什麼、服務誰、目前有哪些限制與優先順序。設定檔是第二大腦的一部分，不是一次填完後永遠不變的商業計畫。

## 固定位置

- 設定檔：`sources/strategy/solopreneur-profile.md`
- 檔案不存在或 frontmatter 為 `status: not_configured` 時，視為尚未完成。
- 公開專案只提供空白範本；不得把實際使用者內容回傳到公開 repository。

## 啟動條件

符合下列任一情況時使用：

- 使用者明確要求建立、查看、修改或重新整理一人公司設定。
- 使用者詢問創業方向、定位、客群、產品、定價方向、內容通路、優先順序或資源限制，而設定檔能提供必要脈絡。
- 第一次啟動，使用者沒有提出其他明確任務，而且設定檔尚未完成。

不要因設定檔未完成而阻擋使用者已經提出的明確任務。先完成目前任務；只有缺少長期脈絡確實會影響結果時，才用一句話提示之後可以補設定檔。

## 第一次建立

不要一次要求填寫長表格。一次只問一個主要問題，依回答逐步涵蓋：

1. **目前狀態**：正在構想、驗證、已有收入，或其他階段。
2. **想服務的人**：目標使用者與他們真正遇到的問題。
3. **提供的價值**：目前或預計提供的產品、服務與成果。
4. **取得客戶的方法**：內容、社群、搜尋、合作、名單或其他通路。
5. **已有資產**：知識、案例、內容、工具、社群、名單與可重複流程。
6. **限制與界線**：可投入時間、預算方向、不能做的事與不想犧牲的原則。
7. **近期優先事項**：未來一至三個月最重要的假設、行動與驗證指標。
8. **仍待確認**：目前不知道或尚未決定的問題。

使用者不確定時保留「待確認」，不要替使用者猜答案。

## 寫入流程

1. 先讀取既有設定檔；更新時保留仍有效的內容與重要決策脈絡。
2. 將使用者直接說出的內容、AI 整理與尚待驗證的推論分開。
3. 先在對話中顯示準備新增、修改與保留的內容。
4. 取得使用者明確確認後才寫檔。
5. 完成首次設定後將 `status` 改為 `active`，更新 `updated_on`。
6. 重大方向改變時，在「重要決策與變更」追加日期、原因與被取代內容，不靜默改寫歷史。

## 在創業問題中使用

1. 先讀取設定檔。
2. 使用 `/knowledge-source-retrieval` 定向尋找相關讀書筆記、Wiki、決策與來源。
3. 分清設定檔中的已確認方向、仍待驗證假設與過去決策。
4. 使用者感到困惑、需要比較選項或挑戰假設時，交給 `/socratic-dialogue`。
5. 設定檔和最新明確說法衝突時，先指出差異；只有使用者要求更新並確認內容後才寫回。

## 安全與邊界

- 不要求使用者提供銀行帳號、密碼、Token、身分證號或不必要的敏感資料。
- 精確收入、資產、負債與客戶個資不是必要欄位；若任務確實需要，先說明用途並讓使用者決定是否提供。
- 不把設定檔當成永久人格、不可改變承諾或自動執行商業決策的授權。
- 對外發布、付款、聯絡客戶、建立帳號或修改遠端服務，仍須依各工作流取得明確授權。
