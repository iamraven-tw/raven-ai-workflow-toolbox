# v0.1.0-preview.1 發布驗收

產品：Raven AI 一人公司工具包。驗收日期：2026-09-13。

本次範圍包含根層品牌與發行文件、AI 影片 Windows 相容性、Google 上游跨平台驗證、社群 OAuth 維護、官網七技能；AI 知識庫與 Agent 盤點一併回歸驗證。既有安裝識別码與固定上游保持相容。

各包靜態驗證另行通過。略過來自 Windows symlink 權限限制與未啟用的原生憑證庫驗收；不等於通過。此輪沒有登入社群平台、建立排程或操作真實網站。

- 官網：Windows Node 24.19.0／npm 10.9.3；六主題與啟用四種服務入口的真實 Astro 建置、安裝生命週期、備份與隔離還原。沒有向供應商提交表單。
- AI 影片：從公開 v0.1.1 重新下載，核對資產 SHA-256 與全部補丁輸入／輸出，使用既有隔離 Python runtime 執行 98 項引擎測試與 FFmpeg 合成影片 smoke test。沒有下載模型；合成逐字稿與 CKIP fixture 不代表模型推論驗收。
- Google：固定 commit、tree、MIT LICENSE 雜湊與乾淨 clone 再核對；相容性調整只在暫存測試副本，實際安裝來源不變。
- 社群：第一次系統 Python 測試因缺少 IANA 時區資料失敗；切換既有隔離 tzdata 2026.3 與隨附 Python 3.12／Pillow 12.3.0 後完整重跑成功。不是刪除失敗案例或改成略過。

## 逐檔與公開邊界

逐一納入理由見 [發行範圍清單](release-scope.json)。所有未提交的非忽略檔案均歸入本次 Preview；沒有另外夾帶未知候選、私人案例或其他產品。六包皆宣告可安裝候選，規劃中能力仍不能當成已實作技能。

公開前檢查原有 54 個提交、840 個歷史 blob，未觸發秘密值／私人路徑／禁入檔案規則；當前來源另通過各包公開邊界、固定依賴、frontmatter、相對連結與授權檢查。新增 Video-Use 補丁完整 MIT 授權，保留官網預覽內嵌第三方程式授權；不改動上游授權或固定補丁雜湊。

遠端發布與公開下載結果記錄於同一版本的 GitHub prerelease，不把尚未完成的外部動作寫成已通過，也不移動已發布 tag 修改本報告。

發布封包只包含 Git tag 的受追蹤檔案；不包含 `.local`、快取、模型、虛擬環境、原生憑證或使用者素材。歷史唯讀檢查與每包隱私／第三方來源檢查不等於完整資安或法律認證。

仍待正式支援驗收：另一臺電腦、各平台實際登入／OAuth／發布、Windows 模型推論，以及官網 Cloudflare 部署、自訂網域、外部服務與排程。公開 Preview 不自動解除這些關卡。
