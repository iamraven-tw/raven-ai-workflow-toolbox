# 公開發行與商業邊界

## 狀態

本文件是 MVP 決策基準，不是法律意見。Raven AI 一人公司工具包 自行撰寫的公開核心已決定採 Apache License 2.0；付費產品內容、銷售條款與實際營運責任仍須在推出付費產品前另外確認。

Apache License 2.0 允許他人依授權條件商業使用、修改與重新散布公開核心。Raven 名稱、Logo 與其他商標不包含在授權範圍內。未來付費內容必須保存在獨立的私人 repository 或清楚分離的商業發行物。

## 公開核心

預計放在公開 GitHub repository 的內容包括：

- 可重複使用的工作流程與技能。
- 安裝 manifest、範例設定與驗證方式。
- 不含私人資料的工作區範本。
- 第三方來源、版本、授權與已知限制。
- 一般使用者能自行執行的測試與問題回報資料。

公開 Git 歷史不得含有 Raven 私人內容、品牌資產、真實帳號、未公開文章、學員資料、模型快取、原始影片、成品、憑證、本機絕對路徑或付費專屬內容。

## 未來付費層

付費價值可以來自進階技能包、精選範本、課程、顧問、代安裝、維護更新、保固或其他服務。付費專屬檔案應放在獨立的私人 repository 或清楚分離的商業授權發行物，不能先提交到公開 repository 再嘗試隱藏。

如果公開核心採用標準開源授權，應預期其他人可以在授權條件內使用、修改與重新散布。商業模式不能只依賴對公開程式碼的排他控制。

## 第一次公開發布前的決策門檻

必須先確認：

1. 公開核心採用的根授權：已決定為 Apache License 2.0。
2. 各技能包是否沿用根授權或使用自己的相容授權。
3. 付費內容的 repository、授權與交付邊界。
4. 第三方依賴與素材的商業使用、修改及散布條件。
5. 商標、名稱、免責、隱私、支援範圍與安全回報方式。
6. 若實際收費，另行完成適用的銷售、稅務與消費者權益專業確認。

根授權已完成決策，但其他門檻尚未完成前，仍不得把 repository 宣稱為已完成的公開發行版。
